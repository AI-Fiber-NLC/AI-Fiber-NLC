# CONTRIBUTING.md — AI-Fiber-NLC

Welcome! Here's a quick guide to get started.

## Developer Setup

```bash
git clone https://github.com/AI-Fiber-NLC/AI-Fiber-NLC.git
cd AI-Fiber-NLC
pip install -e ".[dev]"

# Verify installation
pytest tests/ -v
ruff check src/ tests/
```

## Contribution Types

### 1. Code (Models / Bug Fixes / Features)

1. Open an issue first (unless it's a trivial fix)
2. Fork → branch → develop
3. Make sure `pytest` + `ruff` pass
4. Open a PR and fill in the PR template

### 2. Benchmark Submission

1. Use the "Benchmark Submission" issue template
2. Include all required fields
3. Results must be generated by the official benchmark script
4. Attach a contribution signature (see below)

### 3. Documentation

Open a PR directly editing `docs/` or `README.md`.

## Contribution Signature (Ed25519 Signing)

Phase 0-1 uses Ed25519 local signing (batch on-chain later):

```bash
# Generate key pair (first time)
python tools/sign.py keygen --author "Your Name <email>"

# Sign a model file
python tools/sign.py sign --model-file models/my_model.pt
```

The signature file (`*.sig`) is submitted alongside the PR.

## Code Style

- **Lint**: `ruff` (auto-formatter)
- **Type check**: `mypy`
- **Tests**: `pytest`

```bash
# Format
ruff format src/ tests/

# Check
ruff check src/ tests/
mypy src/
```

## Benchmark Submission Checklist

- [ ] Results generated by the official benchmark script
- [ ] At least 3 power points included
- [ ] Seed matches the scene configuration
- [ ] Contribution signature attached
- [ ] Benchmark Submission template fully filled
